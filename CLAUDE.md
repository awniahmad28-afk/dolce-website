# Working rules for this repo

- **Wait for explicit go-ahead before implementing.** When the user asks a question, raises an idea, or describes a problem, propose the plan/approach in chat first and wait for them to confirm (e.g. "yes", "do it", "go ahead") before editing files, committing, or pushing. Do not jump straight to implementation on a request.
- **Default to pushing straight to the live site.** Once implementing, push to `main` (live site: https://dolceclinic.com/) and keep the Artifact preview in sync — don't stop at an Artifact-only preview by default. Only hold a change back as preview-only (not pushed to `main`) when the user explicitly asks to preview it first.
